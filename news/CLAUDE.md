# news/CLAUDE.md

이 파일은 `news/` 폴더 안의 파일을 다룰 때만 참고하는 세부 규칙이다.
프로젝트 전체 공통 규칙(보안, 실패 허용 원칙, 작업 순서 원칙 등)은 루트 [CLAUDE.md](../CLAUDE.md)를 따르며, 여기서는 반복하지 않는다.

---

## 담당 범위

이 폴더는 알람 앱의 **'최근뉴스' 조회 및 TTS 브리핑 기능**만 담당한다. 이 범위를 벗어나는 로직(알람 자체 설정/재생, 날씨 표시 등)은 이 폴더에 두지 않는다.

---

## 파일 구조 규칙

- 이 폴더에는 **`news.js`, `news.css` 두 파일만** 둔다.
- 새로운 하위 파일/폴더를 임의로 만들지 않는다. 기능이 커져서 분리가 필요하다고 판단되면, 먼저 사용자에게 확인을 구한 뒤 진행한다.

---

## 함수 이름 규칙

함수의 역할에 따라 접두사를 다음과 같이 통일한다.

- **`fetchXxx`** — 데이터를 가져오는 함수 (예: 네이버 뉴스 API 호출 등 비동기 조회)
- **`renderXxx`** — 화면에 그리는 함수 (DOM 업데이트, 카드 렌더링 등)
- **`buildXxx` / `stripXxx`** — 순수 변환 함수 (데이터 가공, HTML 태그 제거 등 부수효과 없는 변환)

이 접두사 규칙에서 벗어나는 이름(예: `getNews`, `showCard`, `parseData` 등)을 사용하지 않는다.

---

## script.js와의 관계

- `script.js`(알람 로직)는 `news.js`가 제공하는 함수를 **호출만** 한다.
- 뉴스 검색, 데이터 가공, TTS 재생 등 뉴스 관련 로직을 `script.js` 안에 직접 작성하지 않는다. 관련 로직은 반드시 `news.js`에 작성한다.
